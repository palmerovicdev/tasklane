Turns the TODO comment at the caret into a Tasklane task: its text becomes the task, its keyword a tag, and the task is anchored to that line of code.

If the comment holds nothing but the TODO, it is removed from the code once the task is created — the gutter mark of the task takes its place. A comment that says more, such as documentation with a TODO line inside, is left untouched.

The TODO patterns are the IDE's own, from Settings | Editor | TODO.
